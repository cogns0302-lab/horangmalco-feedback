# 2027 호랑말코 2차 면접 가이드북 (한글 파일)

기존 「호랑말코 수업실연 가이드북」과 같은 서식으로 만든 **면접 가이드북**입니다.

## 결과물 (`dist/`)

| 파일 | 내용 |
|---|---|
| `2027 호랑말코 2차 면접 가이드북.hwpx` | 한글 파일. A4, 표지 포함 약 45쪽(추정) |
| `원고.txt` | 본문 글자만 뽑은 것(한글 없이 내용을 훑어볼 때) |

## 목차

- I. 준비(1) — 공고문 확인, 면접 진행 절차
- II. 준비(2) — 스터디(2027학년도 일정 표·달력), 준비물(교재 및 자료, 시책, 만능틀)
- III. 면접 — 면접 안내, 기출 통계, 공부방법, 구상실, 시험실
- IV. 피드백 & 평가 기준 — 시간, 답변, 태도 (2026학년도 평가원 기출을 예로)

## 다시 만들기

```bash
python3 src/make.py
```

파이썬 표준 라이브러리만 씁니다(미리보기 그림을 새로 그릴 때만 Pillow 필요).

## 구성

```
src/hx.py           문단·표·달력을 HWPX XML 로 바꾸는 도우미
src/c_front.py      표지 · 프롤로그 · 목차 · I장
src/c_prep2.py      II장
src/c_interview.py  III장
src/c_feedback.py   IV장
src/make.py         원고를 묶어 .hwpx 로 저장
template/           기존 수업실연 가이드북에서 가져온 스타일 정의(글자·문단·테두리 모양, 용지 설정)
```

원고는 `c_*.py` 에 들어 있습니다. 글 안의 `**굵게**`, `__밑줄__`, `[[굵은 밑줄]]`, `{{파랑}}`, `!!빨강!!` 표시는
한글의 글자 모양으로 바뀝니다. 줄 배치 정보는 넣지 않으며, 한글이 파일을 열 때 계산합니다
(`server/pipeline/hwpx.py` 와 같은 방식).

## 내용의 기준

- 일정: 2027학년도 임용시험(유초특 1차 2026.11.7 → 발표 12.9 → 2차 2027.1.6~ → 최종 1.27 /
  중특 1차 2026.11.28 → 발표 12.29 → 2차 2027.1.20~21 → 최종 2.5).
- 지역별 면접 형식·시간: 각 시·도 2026학년도(작년) 2차 시험 공고 기준. **2027학년도 공고가 나오면 I장의 표를 갱신해야 합니다.**
- 기출 통계: 2차 면접 문제는 공식 공개되지 않으므로, 2027 대비 수험서(면접레시피 · 원페이지 · 지니, 유초특은 박해인)의 복기 문제에서
  주제만 요약했습니다.
- 수험서의 문제 원문·모범답안·예시답안은 싣지 않았습니다. 가이드북의 예시 답변·구상지·답변 틀은 새로 쓴 것입니다.
- II장 스터디는 기존 수업실연 가이드북의 글을 면접에 맞게 고쳐 옮겼습니다.
