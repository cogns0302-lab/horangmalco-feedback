# 2027학년도 유·초등 임용 2차 가이드 (무료 배포 자료 + 인스타 캐러셀)

호랑말코 임용 웹앱 「임용 2차 팁」과 17개 시·도교육청 공고문, 2027 대비 2차 수험서를 바탕으로 만든
**30쪽 PDF 가이드**와, 이 자료를 알리는 **인스타그램 캐러셀(정지 이미지 + 모션 영상)** 입니다.

## 결과물 (`dist/`)

| 파일 | 내용 |
|---|---|
| `27학년도_유초등_임용2차_가이드.pdf` | A4 30쪽. 지역 구분 · 공고문 · 60일 로드맵 · 스터디 · 면접 · 수업실연 · 과정안 · 시책 · 교재 · QnA |

| `carousel/00_전체_이어보기.mp4` | 10장을 이어 붙인 한 편 (약 65초, 릴스·피드 영상용) |
| `carousel/캡션.txt` | 게시글 문구 초안 |

마지막 슬라이드는 받는 방법에 따라 두 가지로 만들었습니다. 쓰는 쪽만 올리면 됩니다.
`10_받는법_프로필링크` (프로필 링크에서 받기) / `10_받는법_댓글DM` (댓글 → DM 발송).

## 다시 만들기

```bash
bash fonts.sh                 # Pretendard · Black Han Sans 설치 (처음 한 번)
node guide/build.js           # PDF + 쪽별 미리보기(guide/build/png)
node carousel/render.js       # 캐러셀 PNG + MP4 (ffmpeg 필요, 5분 안팎)
node carousel/render.js --stills        # 정지 이미지만
node carousel/render.js --only=1,4      # 일부 슬라이드만
```

- Node와 Playwright(Chromium), ffmpeg가 필요합니다.
- `guide/build.js` 는 쪽마다 글이 넘치는지 검사해 알려 줍니다.
- 캐러셀을 고친 뒤 표지에 쓰는 쪽 그림을 바꾸려면 `guide/build/png/pNN.png` 를 줄여 `carousel/assets/pageNN.jpg` 로 덮어씁니다.

## 구성

```
guide/pages/*.html   쪽 원고. "<!--page ...-->" 한 줄이 한 쪽의 시작(제목·출처는 이 줄의 속성)
guide/data.js        도표 데이터(지역 구분, 지역별 배점·시간)
guide/lib.js         아이콘 · 누적 막대 · 타일 지도 · 60일 달력을 그리는 스크립트
guide/styles.css     쪽 틀과 공통 요소 / guide/charts.css  도표와 쪽별 요소
carousel/carousel.html · carousel.css   슬라이드 10장 (움직임은 모두 CSS 애니메이션)
carousel/render.js   애니메이션 시간을 프레임마다 옮겨 가며 찍어 MP4로 묶음
assets/              마스코트(웹앱의 tiger.png 를 확대 보정), 웹앱 QR
```

## 내용의 기준

- 일정: 17개 시·도 「2027학년도 유치원·초등·특수학교(유치원·초등) 교사 임용시험 시행계획 공고」(2026.9.9)
- 지역별 배점·시간·유의사항: 각 시·도 「2026학년도 제1차 합격자 및 제2차 시험 시행계획 공고」(2025.12).
  **작년 기준**이므로 2027학년도 2차 공고(1차 합격 발표일, 12.9)가 나오면 `guide/data.js` 와 8~11쪽을 갱신해야 합니다.
- 도표에서 ※ 표시한 경북·대전·경남·전남은 공고문 원문 대신 2027 대비 수험서의 지역별 정리표(특수 초등 기준)를 따랐습니다.
- 수험서는 사실·구조만 참고했고, 문제·예시 답안·스크립트는 싣지 않았습니다. 가이드 안의 예시 문항·구상지는 새로 쓴 것입니다.
